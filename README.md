# Library Management System

A web-based Library Management System built with **HTML** and **Python** for managing books, members, and transactions effectively.

## Features

- **Book Management**: Add, update, and remove books in the library catalog.
- **Member Management**: Register new members and maintain member details.
- **Transaction Management**: Handle book lending, returns, and overdue fines.
- **Search Functionality**: Quickly search for books or members.
- **Responsive Design**: User-friendly interface for both desktop and mobile devices.

## Technologies Used

- **Frontend**: HTML (61.2%)
- **Backend**: Python (38.8%)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Osa2ma/LibraryManagementSystem.git

2. Navigate to the project directory:
   ```bash
   cd LibraryManagementSystem

3. Install required dependencies:
   ```bash
   pip install -r requirements.txt

4. Run the application:
   ```bash
   python app.py

## Usage
1. Open the application in your web browser.
2. Use the provided interface to manage books, members, and transactions.
